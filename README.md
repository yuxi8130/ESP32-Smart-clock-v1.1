# ESP32-Smart-Clock-V1.1

基于 ESP32 的智能桌面时钟 & 情感化桌宠（V1.1 状态机重构版）。

## 🚀 项目简介
本项目旨在探索边缘计算硬件如何为冰冷代码注入情绪价值。采用敏捷开发（MVP），从基础的桌面时钟逐步迭代为具备交互能力的 AI 桌宠。

## ✨ 核心功能 (V1.1)
*   **非阻塞架构**：彻底摒弃 `delay()`，使用 `millis()` 时间戳实现按键、屏幕刷新与闹钟调度的并行。
*   **情感化交互**：内置 `PetState` 状态机（0正常/1困倦/2惊醒），支持待机犯困 `(=u_u=) zZ` 与按键叫醒 `(=O_O=) !!`。
*   **UI 过渡动画**：按键切换模式时，加入 1 秒的过渡表情动画，告别生硬跳变。
*   **防抖与安全机制**：自定义 50ms 延迟微阻塞防抖，解决劣质面包板物理虚接导致的按键连发。

## 🛠️ 硬件清单
*   **主控**：ESP32 DevKit V1
*   **显示**：0.96" I2C OLED (SSD1315/SSD1306)
*   **时钟**：DS3231 RTC 模块
*   **交互**：轻触按键 x4，无源蜂鸣器模块

## 🩸 研发踩坑记录
*   **短路发烫**：利用控制变量法逐路拔外设，定位面包板内部走线过密短接。
*   **悬空直连法**：绕过面包板直连主控反推 I2C 通信虚接。
*   **代价**：旧 OLED 屏幕 U2 芯片因一次严重短路永久击穿。
