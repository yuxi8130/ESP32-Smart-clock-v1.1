# ESP32-Smart-Clock

基于 ESP32 的多功能智能桌面时钟与情感化桌宠。

## ✨ 核心功能
*   **非阻塞架构**：全盘弃用 delay()，基于 millis() 时间戳实现按键、UI渲染、闹钟的并发调度。
*   **I2C 极致提速**：查阅芯片手册，将 I2C 总线从 100kHz 提升至 400kHz，彻底解决按键粘滞感。
*   **情感化交互 UI**：白天保持时钟工具属性；深夜自动隐藏时间，全屏手绘（drawLine）闭眼巨眼，提供陪伴感。
*   **硬件排雷**：经历短路、烧屏，掌握控制变量法与悬空直连法。

## 🛠️ 技术栈
*   ESP32 (Arduino 框架)
*   SSD1306 (I2C OLED)
*   DS3231 (RTC 实时时钟)
*   
## 🛠️ 硬件清单
*   **主控**：ESP32 DevKit V1
*   **显示**：0.96" I2C OLED (SSD1315/SSD1306)
*   **时钟**：DS3231 RTC 模块
*   **交互**：轻触按键 x4，无源蜂鸣器模块

## 🩸 研发踩坑记录
*   **短路发烫**：利用控制变量法逐路拔外设，定位面包板内部走线过密短接。
*   **悬空直连法**：绕过面包板直连主控反推 I2C 通信虚接。
*   **代价**：旧 OLED 屏幕 U2 芯片因一次严重短路永久击穿。
